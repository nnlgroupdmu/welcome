## 实验室社群计划：为什么是 Memos？

各位同学，

为了打破实验室成员之间相对孤立的实验状态，共建更加团结的小组，我们正式上线了内网动态广场（Memos）。这里不是交作业或写正式周报的死板系统，而是属于我们实验室的“技术朋友圈”与“碎片化博客”。

这是笔者搭建服务器环境以来最喜欢的一个服务，也是我最核心的价值诉求的具象化。

新研一的同学们已经分不到工位，而研三的师兄师姐也将在他们入住实验室时离开。我们的实验室一度非常亲切熟悉的集体氛围正在消退。如果研究生时期的生活只是自己对着电脑折腾，那我们会失去多少原本可能的精彩？如今的网络发达，想必同学们都很熟悉 QQ 群、微信群、朋友圈、微博等形式。另一方面，在 GitHub 上寻找服务器组件时，开源社区的丰沛活力和取之不尽的宝藏资源令我心驰神往。我想，我们完全可以借鉴这些形式，用一个动态笔记广场，把大家分享的经验和资源，以及研究生活中的点点滴滴收集起来。有一天，当我们回过头，会觉得这一切都是珍贵的回忆，不是吗？

### 1. 为什么推荐 Markdown 笔记？

我们平时的日常工作——无论是配好了一个复杂的环境、写了一段精简的数据预处理脚本，还是读了一篇好论文——都非常值得用文档记录下来。
在今天，产出这类笔记的门槛已经极低。你完全可以随手写下碎片的思路，辅以 AI 的总结和格式整理，几分钟就能产出一篇高质量的记录。这种顺手而为的习惯，在日后自己查找（避免重复踩坑）以及与同门分享时，将产生巨大的价值。

### 2. 为什么是 Markdown？—— AI 时代的最优格式

Markdown 是纯文本，这意味着它具有最高的兼容性和最轻量的体积。更重要的是，**它是 AI 时代天然对大模型最友好的数据格式**。
我们现在用 Markdown 规范记录的每一段环境配置、每一次报错解决、每一个实验心得，都在以统一的格式构建实验室自己的“本地知识库”。这不仅方便当前的全文检索，更为我们日后将这些数据作为知识库，直接接入团队定制的本地 AI 工作流（如 RAG 检索增强）做好了最完美的格式准备。

### 3. 我们的愿景：留下你的痕迹

我们希望能构建一个活跃、热心互助且勤于尝试的实验室社区。
科研往往面临巨大的不确定性，在狭窄的领域里独自摸索容易让人陷入孤立。我们希望在这里，大家能更主动地表达和分享。更重要的一点是：**不要让毕业带走你在这里积累的一切。**
将你的踩坑经验、好用的轮子留在这个“灵感港湾”里，作为你对实验室的持久贡献。后来的学弟学妹会因为看到你的记录而少走弯路，而这里也会因为我们每个人的加入，变得越来越好。
