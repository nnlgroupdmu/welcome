## 一、注册和登记

### 1. 注册账号

* 请自行访问上述网址，点击**「注册」**。
* **【注册规范】**：**用户名请一律使用拼音全拼**（如 `zhangsan` 或 `lisi`），禁止使用火星文或非主流英文名，方便后续拉入组织。
* 注册后即可直接登录，**不需要**等待管理员审批。

### 2. 登记以加入组织

为了方便管理大家毕业离校后的代码，请大家都加入创建好的 Gitea 组织 **`nnl-group`**。

1. **登记名字**：请在共享文档 `[此处放文档链接]` 中登记你注册的 **Gitea 用户名**。
2. **等待入组**：管理员会在每周五统一把你拉入实验室组织。
3. **资产归公**：当你被拉入组织后，请进入你之前创建的每一个重要仓库，点击右上角的 **「设置 (Settings)」** ➡️ 滑到最下方红框 ➡️ 点击 **「转移所有权 (Transfer Ownership)」** ➡️ 将所有人变更为 **`nnl-group`**。


## 二、使用 Gitea

### 3. 如何把代码传上去？

* 登录后，点击右上角的 **`+`** 号 ➡️ **「新建仓库」**。
* **所有者 (Owner)**：选组织 `nnl-group`，还没加入的话，先保持为你自己的用户名，后续转交所有权。
* **仓库名称**：建议使用英文，如 `transformer-mnist`。
* **可见性**：选为「公开」即可（仅内网，代码是安全的）。
* 点击创建。

然后就是和 GitHub 的同款操作了，在你的本地电脑（笔记本或服务器）的代码文件夹里，打开终端，按照页面提示敲入命令：

```bash
# 1. 初始化并提交本地代码
git init
git add .
git commit -m "first commit"

# 2. 关联我们自己的服务器（内网/Tailscale地址可以在Welcome主站用工具一键转换）
git remote add origin http://192.168.31.240:3000/你的用户名/你的仓库名.git

# 3. 推送代码
git push -u origin main

```

*提示： `main` 是你的分支的名字

## ⚠️ 避坑指南（在使用前必须知道的事）

* **关于 GitHub Actions 报错（可完全无视）**：如果你是从 GitHub 上 `clone` 下来的成熟项目，里面带有 `.github/workflows` 文件夹，当你 `push` 到我们服务器时，网页上可能会弹出一个 Actions 运行失败的红叉提示。**这完全不影响你的代码存储**，请直接无视它。
* **大文件请不要直接硬塞**：如果你的项目里包含几个 GB 的数据集、`.pth` 模型权重文件，**请不要**用 `git add` 传上来，会导致内网卡死。请将它们写进 `.gitignore` 忽略掉，Gitea 只用来存纯代码文本。
