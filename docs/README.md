# NNL Group Lab Open Hub 维护文档

本目录保存网站项目的工程维护文档，面向项目维护者和 AI 协作者。面向实验室成员的使用指南仍放在 `public/docs/`，由 Docsify 在线文档站展示。

## 推荐阅读顺序

1. [PROJECT_BRIEF.md](PROJECT_BRIEF.md)  
   日常短摘要。适合快速了解项目定位、主要功能、运行命令和网络模型。

2. [AI_HANDOFF_PROMPT.md](AI_HANDOFF_PROMPT.md)  
   AI 交接提示词。适合直接粘贴给 Codex、ChatGPT 或其他代码助手，让它快速进入项目上下文。

3. [SPECIFICATION.md](SPECIFICATION.md)  
   详尽规格说明。记录产品目标、页面结构、数据流、配置入口、本地持久化键和维护边界。

## 文档边界

- `docs/`：工程维护、AI 协作、规格说明。
- `public/docs/`：实验室成员在线阅读的使用指南、服务器说明、入网说明和工具教程。
- 根目录 `README.md`：项目入口与最短说明，避免承载过多维护细节。
