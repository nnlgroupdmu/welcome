# 更新历史

本页面记录实验室服务器基础设施及文档手册的更新简报。

---

## 2026-5-8

### 新增
* 自制基础镜像 `base_image:v1` 代替过去推荐的 pytorch 镜像，加入了常用工具和 ssh 服务支持。
* 修正的 docker run 指令模板，增加共享内存大小设置，端口号设置，disk2 默认挂载等。
* 全局脚本 checkport 供所有用户检查 docker container 端口占用
* 添加 5090 服务器 AI 提示词

### 优化
* 改善网页表现，添加自制 Favicon 和网站名。

---

## 2026-4-30
### 新增
* 安装 Task Spooler 作为共享任务队列。
* 添加了motd（message of the day），为避免 ssh 工具的不一致，将在每个 bash 显示（bashrc）。
* 在 server guide 添加了对应章节，更新了显卡管理描述。

### 优化
* 增加文字提示，提醒处理移动设备拷贝的权限问题。
* 删减过时内容，调整多处表达。
